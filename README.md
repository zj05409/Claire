# Claire 的个人网站

用于展示 Claire 的个人简介、作文、画作、编程作品、阅读、电影和游戏记录。

## 发布新作文

双击 `发布新作文.bat`：

1. 选择两张或更多作文照片并调整顺序。
2. 工具会根据第一张照片文件名提供标题建议；确认正确即可，不正确时直接修改。
3. 点击发布后，工具会自动拼接图片、更新 `data.js`、提交并推送到 GitHub。

工具中的“删除已发布作文”可以选择一篇公开作文，并自动删除 GitHub 中的图片和网站记录。

原来的“小澄立刻行动器”保留在 `/doit/`。

个人网站只负责展示公开作文。作文列表点击后进入独立详情页，详情页展示完整长图，并可点击打开原始大图。
