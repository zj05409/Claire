# Claire 的个人网站

用于展示 Claire 的个人简介、作文、画作、编程作品、阅读、电影和游戏记录。

## 本地运行网站

双击 `打开个人网站.bat`，工具会自动启动本地网站并打开浏览器。

关闭本地网站时，直接关闭弹出的命令窗口，或在窗口里按 `Ctrl+C`。

## 发布新作文

双击 `发布新作文.bat`：

1. 选择两张或更多作文照片，或点击“拍照添加”直接拍照。
2. 调整照片顺序。
3. 工具会根据第一张照片识别标题；确认正确即可，不正确时直接修改。
4. 点击发布后，工具会自动拼接图片、更新 `data.js`、提交并推送到 GitHub。

拍照得到的原始照片会先保存在本地 `captured/` 文件夹。发布时，工具会自动把需要公开的图片复制到网站的 `assets/compositions/` 目录。

## 拍照功能

第一次使用拍照按钮前，先确认 Windows 可以使用摄像头：

1. 如果要用安卓手机拍照，请先在 Windows 的“手机连接 / Phone Link”或“移动设备”设置里，把安卓手机连接成电脑摄像头。
2. 如果电脑提示缺少拍照支持，请双击 `安装拍照支持.bat` 安装。
3. 回到发布工具，点击“拍照添加”或“拍照选择画作”。
4. 预览窗口中按空格键或 Enter 保存照片，按 `C` 切换摄像头，按 Esc 取消。
5. 如果第一次打开的不是安卓手机，而是 Iriun Webcam 之类的虚拟摄像头，按 `C` 切到正确画面后保存一次；工具会记住这次的摄像头编号，下次优先使用它。

工具中的“删除已发布作文”可以选择一篇公开作文，并自动删除 GitHub 中的图片和网站记录。

标题识别优先使用开源 PaddleOCR。当前电脑已经安装；在其他电脑首次使用时，可双击 `安装高精度OCR.bat` 安装。首次识别会下载模型。

## 发布新画作

双击 `发布新画作.bat`，选择一张画作图片，或点击“拍照选择画作”直接拍照；填写画作名称和可选介绍，然后发布。工具也支持删除已发布画作。

原来的“小澄立刻行动器”保留在 `/doit/`。

个人网站只负责展示公开作文。作文列表点击后进入独立详情页，详情页展示完整长图，并可点击打开原始大图。
