# Claire 的个人网站

用于展示 Claire 的个人简介、作文、画作、编程作品、阅读、电影和游戏记录。

## 追加内容

编辑 `data.js`，在对应分类的数组中添加新条目，然后提交并推送到 `main` 分支。

画作图片放入 `assets/artworks/`，并在 `data.js` 的 `image` 字段中填写对应路径。

原来的“小澄立刻行动器”保留在 `/doit/`。

“我的作文”区域默认显示公开作文列表。点击“上传作文”并通过密码验证后，可以输入标题、选择两张或更多照片并自动拼接。公开作文图片保存在 GitHub 仓库的 `assets/compositions/` 中。
